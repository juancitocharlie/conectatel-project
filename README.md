# **Análisis estadístico para detectar patrones y outliers de una empresa de telecomunicaciones**

Este proyecto muestra el análisis de datos sobre la empresa ConnectaTel y los procesos desde la preparación y limpieza de datos hasta el análisis estadístico encaminado para detectar patrones y outliers.


## **Contenido del repositorio**:
El cuaderno "telecom_analysis.ipynb" en el que están todas las fases del análisis, este archivo se ejecuta en el entorno de Jupyter Notebooks o en Google Colab

### **Los datasets que aportan la información para este análisis**:
plans.csv : Tabla que contiene los planes que ofrece la empresa 2 registros.
users_latam.csv: Tabla que contiene la información de los usuarios(clientes),4.000 registros.
usage.csv: Tabla que contiene los registros de las actividades de los usuarios en la plataforma.

- b. datasets: plans.csv y users_latam.csv y usage.csv

## 🧠 **Objetivo del análisis**

- Identificar problemas de calidad de datos
- Construir un pipeline de limpieza reproducible
- Analizar comportamientos, distribuciones y outliers
- Generar insights para el equipo de Estrategia e Integración de EverPeak

## **Fases del proyecto**:
1. Carga y exploración de los datos.
2. Identificación de problemas de calidad de datos.
3. Limpieza de datos.
4. Estadísticas de uso por usuario.
5. Visualización de distribuciones y outliers.
6. Segmentación de los clientes.
7. Hallazgos y análisis ejecutivo para stakeholders.
